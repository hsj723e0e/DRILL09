# 소년 캐릭터 이동

PRD.md의 요구사항을 pico2d로 구현한 프로그램입니다.

## 실행

Python 3와 pico2d가 필요합니다.

```powershell
python -m pip install pico2d
python character_move.py
```

이미지는 프로그램 파일이 있는 폴더에서 읽으므로 다른 작업 폴더에서도 스크립트 경로를 지정해 실행할 수 있습니다.

## 조작

- 방향키: 상하좌우 이동. 두 축을 함께 누르면 대각선으로 이동합니다.
- 키를 놓으면 정지하며, IDLE 상태에서는 서 있는 고정 프레임을 표시합니다.
- 좌우 이동 시 바라보는 방향이 바뀌고, 상하 이동 시 기존 방향을 유지합니다.
- 반대 방향키를 함께 누르면 해당 축의 이동이 상쇄됩니다.
- 화면 경계에서는 캐릭터 전체가 화면 안에 머물도록 이동을 제한합니다. 경계에서 완전히 멈추면 IDLE 상태가 됩니다.
- ESC 또는 창 닫기: 종료.

## 리소스와 설정

- 배경: `TUK_GROUND.png`
- 캐릭터: `animation_sheet.png` (100 × 100 크기, 8프레임)
- 화면 크기: 1280 × 1024
- 이동 속도: 초당 250픽셀. 대각선에서도 같은 속도를 유지합니다.
- 이동 애니메이션: 초당 12프레임

화면 크기와 속도는 `character_move.py` 상단의 상수로 조정할 수 있습니다.

## 검증

```powershell
python -m unittest -v
```

16개 자동 테스트가 네 방향 이동, IDLE 정지, 방향 유지, 동시 입력, 대각선 속도, 네 경계, 스프라이트 선택과 종료 흐름을 검증합니다. 자동 테스트는 그래픽 창을 열지 않습니다. 실제 pico2d의 소프트웨어 렌더러에서도 이미지 로드, 6프레임 렌더링, 이동·정지 이벤트 처리와 종료를 확인했습니다.
